# Thesis Workspace Rules

When working on any file under `docs/thesis-workspace/`:

1. Read `docs/thesis-workspace/progress.md` first.
2. Read `docs/thesis-workspace/tasks.md`.
3. Check `evidence-matrix.md` before adding project-specific claims.
4. Check `citation-register.md` before using external sources, theory, or tool capabilities.
5. Check `chapter-review-gate.md` before revising or approving a chapter.
6. Mark unsupported project claims as `NEEDS_EVIDENCE`.
7. Mark unsupported theory or tool claims as `NEEDS_SOURCE`.
8. Do not include private Codex/Claude thesis-writing harness details in thesis prose.
9. The Copilot Agentic-AI workflow may appear in thesis prose only as a project automation-testing feature.
10. After editing, update `progress.md` and `next-chat-handoff.md`.
11. Stop at approval gates; do not proceed to the next chapter without user approval.
12. Do not invent test results, metrics, execution outputs, or citation keys.
13. Keep `progress.md` compact: archive dated entries to `progress-archive/YYYY-MM-DD.md`.
