# VNUK Completed Sample Thesis Analysis

## Observed chapter pattern

The VNUK completed sample follows a broad graduation-project structure:

1. Introduction
2. Methodology and Theoretical Background
3. System Analysis and Design
4. Implementation and Results
5. Conclusion and Discussion
6. References

## Application to this project

For the Playwright automation framework thesis, this pattern is adapted into:

1. Introduction
2. Literature Review and Theoretical Background
3. System Analysis and Framework Design
4. Implementation
5. Evaluation and Discussion
6. Conclusion and Future Work

This preserves the VNUK graduation-project flow while better matching an automation framework project.
