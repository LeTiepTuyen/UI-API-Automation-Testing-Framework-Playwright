## Tooling issue found and fixed

- **Reported by Codex:** `latexmk` failed - "MiKTeX cannot find Perl"; only `pdflatex` fallback passed.
- **Root cause (confirmed):** `latexmk` is a Perl script and MiKTeX bundles no Perl interpreter. The failure was a missing Perl on PATH, not a project/syntax error.
- **Fix (no new install):** Perl already exists on this machine via Git for Windows (`D:\Git\Git\usr\bin\perl.exe`). Updated `docs/thesis-latex/scripts/build.ps1` to auto-detect Perl (Strawberry Perl first, then Git for Windows) and prepend it to the session PATH before invoking `latexmk`. No global PATH change; Overleaf (which has its own Perl) is unaffected.
- **Verified:** `latexmk -pdf -file-line-error -interaction=nonstopmode -halt-on-error main.tex` compiled the stub to 22 pages and ran biber. Logged in `compile-issue-log.md` (status: Resolved).
