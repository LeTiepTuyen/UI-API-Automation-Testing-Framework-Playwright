# Progress Archive

This folder stores historical progress entries split by date from `docs/thesis-workspace/progress.md`.

Use `progress.md` for current state, blockers, archive index, current-day entry or latest handoff, and next task. Open an archive file only when older context is needed for traceability or audit.

Do not delete archive files unless the user explicitly asks. Before finishing each thesis work session, move entries from previous dates into a dated archive file and keep the archive index in `progress.md` updated. `progress.md` should not contain detailed entries from multiple dates.
