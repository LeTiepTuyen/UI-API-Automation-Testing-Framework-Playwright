\appendixitem{B}{Test Scenario Matrix}
\label{app:test-scenarios}
\begingroup
\sloppy
\setlength{\emergencystretch}{3em}

This appendix maps the implemented UI and API scenarios to their automated test specifications. The matrix is based on the \code{.ts} test files included in the verified 3 June 2026 full-suite execution evidence. It does not include scenario-design Markdown notes or future scenario candidates that were not part of the verified executable suite.
