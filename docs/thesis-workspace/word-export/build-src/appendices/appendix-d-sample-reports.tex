\subsection*{D.4 Trace Evidence Boundary}

The normal full-suite run did not produce trace artifacts because \code{playwright.config.ts} uses \code{trace: 'on-first-retry'}, and all eighteen tests passed without retry. A supplemental trace run was executed only to demonstrate Playwright's trace-inspection support:

\begin{lstlisting}[language=bash]
npx playwright test tests/ui/profile/view-profile.spec.ts --trace on --reporter=line
\end{lstlisting}

The supplemental trace run produced one passing representative UI test trace. It should be cited only as debugging-support evidence, not as a replacement for the verified full-suite result.
