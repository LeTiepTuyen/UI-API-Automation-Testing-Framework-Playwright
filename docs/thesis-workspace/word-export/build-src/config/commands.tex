% Grouped appendices (international scientific style): all appendices live under
% a single "APPENDICES" entry in the Table of Contents, like the Reference List.
% Each individual appendix is registered as an indented section-level TOC entry.
% Appendices flow continuously to avoid wasted whitespace between them; a small
% vertical gap separates each one, and \needspace keeps an appendix heading from
% being stranded at the bottom of a page (it breaks to the next page only when
% fewer than a few lines remain).
\newcommand{\appendixitem}[2]{%
  \par\addvspace{1.4\baselineskip}%
  \needspace{5\baselineskip}%
  \phantomsection
  \addcontentsline{toc}{section}{Appendix #1: #2}%
  \section*{Appendix #1: #2}%
}
