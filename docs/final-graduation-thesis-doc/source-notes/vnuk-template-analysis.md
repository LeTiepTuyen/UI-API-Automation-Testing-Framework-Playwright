# VNUK Thesis Template Analysis

## Key structural requirements

The VNUK thesis template indicates that the thesis should include:

- title page
- approval page
- table of contents
- optional list of figures
- optional list of tables
- author contribution statement
- acknowledgements
- definitions
- list of abbreviations
- abstract
- main chapters
- reference list
- appendices if needed

## Usage rule

Use this template as the mandatory final Word formatting target. Draft in Markdown first, then migrate into the `.docx` template and apply Word heading, caption, table, and page-numbering styles.
