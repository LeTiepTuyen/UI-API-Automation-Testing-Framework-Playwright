# Thesis Drafting Skill

## Trigger

Use this skill for drafting:

- front matter
- chapter sections
- appendices
- thesis summary
- final `thesis.md`

## Required inputs

Before drafting, read:

- `docs/thesis-workspace/outline.md`
- the target chapter or section file
- relevant entries in `docs/thesis-workspace/evidence-matrix.md`
- relevant entries in `docs/thesis-workspace/citation-register.md`

## Drafting rules

- Use formal academic English.
- Follow the approved outline.
- Do not copy sample thesis wording.
- Keep paragraphs focused and coherent.
- Use cautious academic claims.
- Use `NEEDS_EVIDENCE` for missing execution results.
- Use `NEEDS_SOURCE` for unsupported theory or tool capability claims.
- Keep Markdown clean for later Word migration.

## Review before completion

Check:

- heading hierarchy
- academic tone
- evidence coverage
- citation coverage
- consistency with previous chapters
- absence of placeholders unless intentionally marked

## Completion

After drafting:

- update `tasks.md`
- update `progress.md`
- update `evidence-matrix.md` if new claims were added
- update `citation-register.md` if new sources were introduced

## Private workflow exclusion

Do not include the private Codex thesis-writing workflow, private agents, private skills, or personal AI-assisted writing process in the thesis body, front matter, figures, references, or appendices.
